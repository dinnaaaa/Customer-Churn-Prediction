# Raw Dataset

The raw dataset used in this project consists of four main files:

- `customers.csv`
- `products.csv`
- `transactions.csv`
- `interactions.csv`

The dataset contains customer profile, product, transaction, and customer interaction data.

For this portfolio project, the raw dataset is not included in the repository due to dataset size and repository management considerations.

The analysis and feature engineering process can be reproduced from the notebook using the original dataset source.
